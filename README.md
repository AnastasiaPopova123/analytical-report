# analytical-report
Подготовила аналитический отчёт по учёту спецодежды, инвентаря и спецоснастки: выделила бизнес‑требования (прозрачный контроль выдачи/возврата, сроки эксплуатации, списание по нормам) и пользовательские требования (быстрый поиск по сотруднику и объекту, наглядные статусы, печатные формы карточек).
Стек технологий: 1С:ERP, Google Таблицы, Google Документы.
